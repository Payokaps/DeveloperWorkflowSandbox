# Developer Workflow Sandbox

A simple .NET console application created to practice a professional Git and GitHub development workflow.

## Purpose

This project serves as a learning environment for practicing:

* Git repositories and commits
* Feature branches
* GitHub Issues
* Pull Requests
* Code reviews and merges
* Project documentation
* Releases

## Technologies

* .NET 8
* C#
* Git
* GitHub
* Visual Studio Code

## Requirements

To run this project, install:

* [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
* [Git](https://git-scm.com/)
* [Visual Studio Code](https://code.visualstudio.com/)

## Run the application

Clone the repository:

```powershell
git clone https://github.com/Payokaps/DeveloperWorkflowSandbox.git
```

Navigate to the project:

```powershell
cd DeveloperWorkflowSandbox
```

Run the application:

```powershell
dotnet run
```

Expected output:

```text
Hello, World!
```
